# Maxxie Films Bot

Nouveau bot Telegram, destiné à être hébergé sur le même VPS que le bot précédent.

## État du projet

Dépôt initialisé. Le code du bot et sa configuration de déploiement restent à ajouter.

## Configuration

Les jetons Telegram et autres secrets doivent être conservés dans des variables
d’environnement ou un fichier `.env` local, exclu du dépôt Git.
